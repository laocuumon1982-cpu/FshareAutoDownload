HƯỚNG DẪN CẬP NHẬT TỰ ĐỘNG QUA GITHUB - Fshare Auto Download v6.0
=====================================================================

CÁCH 1 - CẬP NHẬT TỪ FILE ZIP (không cần cài gì)
  1. Tải file FshareAutoDownload_vX.Y.zip mới (không cần giải nén).
  2. Mở tool -> bấm "⟳ Cập nhật" (góc trên bên phải) -> "Cập nhật từ file zip..." -> chọn file.
  3. Tool tự chép đè các file mới, GIỮ NGUYÊN thư mục Data, cất bản cũ vào thư mục _BanCu, rồi tự mở lại.
  Bản exe portable: cũng làm như trên. Tool đặt fshare_auto_idm.py mới cạnh exe và exe sẽ tự chạy code mới
  (không cần chạy lại TaoFileExe.bat, trừ khi bản mới cần thêm thư viện).

CÁCH 2 - TỰ BÁO VÀ TỰ CẬP NHẬT QUA GITHUB (làm 1 lần)
  1. Vào github.com (tài khoản laocuumon1982-cpu) -> New repository -> tên: FshareAutoDownload
     -> chọn Public (tool đọc bản phát hành không cần đăng nhập) -> Create.
     (Repo Private thì tool không đọc được bản phát hành.)
  2. Đưa toàn bộ thư mục tool lên repo, KỂ CẢ thư mục .github (chứa file tự đóng gói exe).
     KHÔNG đưa thư mục Data, rclone.exe, thư mục _BanCu lên (file .gitignore đã loại sẵn).
  3. Mỗi khi có bản mới: tạo Release với tag đúng số phiên bản (VD v6.1).
     GitHub tự đóng gói 2 file: FshareAutoDownload_Portable.zip (bản exe) và FshareAutoDownload_v6.1.zip.
  4. Tool mở lên tự kiểm tra (sau ~15 giây). Có bản mới thì nút đổi thành "⟳ Có bản v6.1" -> bấm -> Có.
  Đổi nguồn cập nhật: bấm "⟳ Cập nhật" khi đang là bản mới nhất -> ô "Nguồn cập nhật".

LƯU Ý
  - Thư mục Data (config.json, owned.json, history.json, rclone.conf) không bao giờ bị ghi đè khi cập nhật.
  - Muốn quay lại bản cũ: lấy file trong thư mục _BanCu đổi tên thành fshare_auto_idm.py.
